## How to Use

- Use clear pixels to clear the screen
- Use redraw to redraw after clearing pixels
- Use undo to undo actions
- Use redo to redo actions
- Use Size +/- to change size of the brush specifically
- export exports at 2x the size, just user art with no background
- emoji1, emoji2, emoji3, and brush are preset brushes, add your own by typing in box and entering
